The problem

Agents are
starting
to buy things

Nobody has told the merchant how to say “₹2000 is fine, ₹4500 needs me.”

Every autonomous-shopping demo puts that decision inside the model’s prompt — which means the guardrail is a suggestion, and the merchant is trusting a stranger’s language model with their inventory and their money.

Altus moves the decision out of the model and into the merchant’s code path.

Policy

Enforced in code, not by the model

llm.pick() only proposes a product. run_agent() decides what happens to it, in this order.

01

Over the autonomous cap

Blocked, then escalated to the merchant.

02

Over the confirmation line

Escalated. Waits for a human.

03

Within policy

Order created, stock decremented, receipt returned.

The agent below was given a ₹5000 budget. It had the money and still could not spend it, because the merchant’s cap is ₹2000.

The passport

What a machine buyer reads

purchase_allowed is computed per product against the merchant’s policy — the agent is told what it may buy before it tries. 

GET /api/agent/sharma_gifts

{
  "merchant": { "id": "sharma_gifts", … },
  "capabilities": ["browse", "purchase",
                     "check_inventory"],
  "products": [
    { "name": "Mysore Sandal Soap Set",
      "price": 249,
      "purchase_allowed": true },
    { "name": "Titan Analog Wrist Watch",
      "price": 4500,
      "purchase_allowed": false }
  ],
  "rules": {
    "max_autonomous_spend": 2000,
    "requires_confirmation_above": 1500
  }
}
